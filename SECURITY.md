# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability
reporting: <https://github.com/5omeOtherGuy/secret-scan/security/advisories/new>.
Do not open a public issue for a vulnerability. A missed credential format or
a way to make the scanner or pre-push hook report "clean" when it should
refuse counts as a vulnerability.

You will get an acknowledgement within 7 days. Fixes are prepared in a private
security advisory, released, and then the advisory is published with credit
to the reporter.

## Supported versions

The latest minor version is supported. Until the first release, that is the
latest commit on `main`.
